## 4. 怎样识别“高阶玩家/高质量策划分析”

不使用粉丝数、点赞数或“我玩了几年”直接判定。先给材料评分，再给作者可信度评分。

| 维度 | 强证据 | 弱证据 |
|---|---|---|
| 条件完整 | 版本、模式、角色/装备、前置状态明确 | 只说“这个最强/最差” |
| 过程可见 | 完整录像、回合/路线/操作步骤、原始数据 | 只有结果截图或剪辑片段 |
| 可复现 | 给出步骤、失败条件、替代方案 | 依赖“相信我” |
| 边界意识 | 说明对谁、何时成立以及反例 | 把个案写成普遍结论 |
| 纠错能力 | 留有勘误、版本更新、承认未知 | 删除反例或不断移动论点 |
| 独立验证 | 能与规则、补丁、录像或第二来源互证 | 只被同圈转述 |

本批中可继续深挖的材料形态包括：小红书对“二次转化”的条件与例外说明、微博对 Boss 机制的条件链、B站对元素反应攻略的逐项纠错。它们显示出较高的信息密度，但作者身份、版本正确性和复现过程仍未验证，所以只能列为“候选专家材料”。

## 5. 下一轮应怎样补样

1. 对“新手概念负荷”增加 `萌新 为什么/看不懂/怎么玩`，同时采热门、最新和中长尾。
2. 对“资源不可逆感”增加 `痛苦号/后悔/卡45/世界等级/养错`，主动找反对“必须卡级”的材料。
3. 对“外部路线负荷”增加 `跟地图/迷路/锚点/一条龙/双屏`，采集视频字幕或人工时间戳。
4. 对候选高阶作者做指定作者采集；从其作品中找完整实验、修订史和反例，不建立个人画像。
5. 用 5 名真实新手的首 90 分钟观察验证：记录未知名词、求助次数、目标解释、失败恢复和离场点。
